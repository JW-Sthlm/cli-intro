# Operator Hour

A weekly internal series for non-coders at Microsoft on AI-first ways of working. Hosted by [Johan Wallquist](https://github.com/JW-Sthlm).

**Season 1: From Zero to Agent.** Six episodes, Tuesdays 10:30-11:15 CET, May 26 to June 30 2026.

This folder collects the artifacts (prompts, recap notes, links to recordings) shared across the season. The course it sits inside is [Copilot CLI: Self-service course for Microsoft partner roles](../self-service-course/README.md).
